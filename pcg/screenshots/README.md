# PCG Mail screenshots

Screens added in this fork, rendered from the real Svelte components with
sample data (no mail server, no real people). Traditional Chinese UI, light
warm theme.

| File | Shows |
|---|---|
| `settings-pst-import.png` | Settings → accounts: a mailbox, a finished PST import ("48,213 messages, 156 contacts"), and one still running with its Stop link. |
| `contacts-list.png` | The Contacts panel: search, People and Groups tabs, import and export. |
| `contacts-edit.png` | A contact opened in place for editing. |
| `contacts-group.png` | A group being edited, adding a member by typing a name. |
